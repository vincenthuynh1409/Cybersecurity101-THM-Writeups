# Cybersecurity 101 TryHackMe Write-Ups

## Description:

### 👋 Introduction:

Yoo, this repository contains my notes, write-ups, lab walkthroughs, and learning progress from completing the Cybersecurity 101 TryHackMe learning path. This repository is organized by TryHackMe rooms/modules (also offered by MIT BWSI Cyber Operations)!
